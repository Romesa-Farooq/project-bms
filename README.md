# SPS-BMS — Employee Management System

A web-based **Business Management System (BMS)** developed as part of the SPS internship project.

The project focuses on building and refining an **Employee Management module** using PHP, Bootstrap, JavaScript, and the Velzon admin dashboard layout.

---

## 📌 Project Overview

SPS-BMS is an employee management interface designed to organize employee information and provide access to different HR-related activities.

The existing BMS structure was integrated with the **Velzon dashboard design** while keeping the existing functionality and project structure intact.

The main goal of the project was to create a clean, responsive, and consistent employee workspace where HR and authorized users can view and manage employee-related information.

## 🎨 UI & Design

The project uses the **Velzon admin dashboard layout** as the primary UI framework.

The existing BMS pages were refined to follow the same design language throughout the system.

The interface uses:

- Bootstrap cards
- Responsive grid layouts
- Velzon-style page headers
- Breadcrumb navigation
- Badges
- Dropdown menus
- Tables
- Forms
- Modals
- Avatars
- Icons
- Responsive navigation
- Consistent buttons and spacing

The goal was to keep the interface professional and consistent rather than creating completely separate designs for individual pages.

# 🧑‍💼 Onboarding

The onboarding section contains different resources and workflows for newly hired employees.

Implemented pages/features include:

### Onboarding Steps

The Onboarding Steps page provides a checklist containing:

1. Write a Detailed Job Description
2. Craft a Compelling Job Offer
3. Create a Pre-Boarding Process
4. Make a Good First Impression
5. Establish the Organization's Culture and Values
6. Introduce the New Hire to the Team
7. Plan a Training Schedule
8. Set Expectations Around the Role and Performance
9. Provide Ongoing Support and Feedback
10. Re-Board When Necessary

Each step allows the user to select:

- Applied
- Not Applied

and add notes.

The page also provides:

- Save functionality
- Reset functionality
- Status feedback
